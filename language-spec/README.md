# AEON Editor Language Spec

Shared editor-facing language definition notes for AEON.

Purpose:

- keep token categories consistent across editors
- document the intended scope names and visual roles
- provide shared sample fixtures for grammar/highlight work

Current targets:

- VS Code / TextMate
- Pulsar
- Sublime Text
- Neovim via Tree-sitter

Files:

- `scopes.md` - canonical token/scope mapping
- `examples/highlight-cases.aeon` - shared fixture for syntax/highlight testing
