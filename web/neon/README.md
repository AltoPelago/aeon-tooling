# Neon Web App

Web app for creating and opening Neon directory containers with AEON files and attachments.

## Features

- Upload AEON source plus attachments (files and folders)
- Optional AEON compaction via `@aeon-tonics/minizer`
- Adjustable Neon settings (magic, checksum, compression)
- Directory manifest preview
- Compression/size reports
- Download generated `.neon` files

## Run

```bash
cd /Users/altopelago/Documents/GitHub/aeon-family/altopelago/aeon-tooling/web/neon
pnpm install
pnpm dev
```

Open `http://localhost:4310`.
